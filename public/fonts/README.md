# Leland font

Sonora uses the Leland SMuFL music font for annotation symbols. If you have the Leland OpenType font downloaded locally, place `Leland.otf` in this directory and the app will prefer the local copy. A web-hosted fallback is also configured so the symbols remain usable when the local font is not present.

Leland is an open-source font distributed under the SIL Open Font License. The upstream project is MuseScoreFonts/Leland.
